## Development

You need [Bun](https://bun.sh) (or Node.js with npm).

```sh
bun install
bun run dev      # http://localhost:8080
bun run build
```

## Environment

Set these in `.env` locally and in the Vercel project settings for production:

- `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, `SUPABASE_PROJECT_ID` and their `VITE_` twins
- `SUPABASE_SERVICE_ROLE_KEY` for storing consultation requests
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`, `CONSULTATION_NOTIFY_TO` for the request notification email

## Deployment

Pushing to `main` deploys to Vercel.
